1. Mục tiêu Sprint

  • Hoàn thành các chức năng thiết yếu về Quản lý Lịch hẹn.
  • Hoàn tất thiết kế giao diện người dùng (UI) cho các trang quan trọng.
  • Hoàn thành API cho các chức năng Quản lý lịch hẹn của bác sĩ.
  • Hoàn thành API cho trang đánh giá bác sĩ và đánh giá phòng khám.
