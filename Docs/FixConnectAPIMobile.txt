📋 Nguyên nhân chi tiết vì sao điện thoại không kết nối được server:
🔴 Vấn đề 1: IP Address Mismatch (Chính)
Cấu hình cũ trong mobile: 10.20.15.108:5000
IP thực tế của máy:       172.168.99.41:5000
➜ Kết quả: Connection refused / Network error

Tại sao IP thay đổi:

DHCP: Router cấp phát IP động, IP có thể thay đổi khi:
Restart máy tính
Reconnect WiFi
Lease time DHCP hết hạn
Thay đổi mạng WiFi
🔴 Vấn đề 2: Network Interface Change
Interface hiện tại: Intel(R) Wi-Fi 6 AX201 160MHz
Subnet khác nhau:
10.20.15.x (subnet cũ)
172.168.99.x (subnet hiện tại)
🔴 Vấn đề 3: Mobile Network Stack
React Native trên Android có đặc điểm:

Không thể dùng localhost như web browser
Phải dùng IP thực của máy host
Tunnel mode giúp bypass network restrictions
🔴 Vấn đề 4: Firewall & Security
Server bind: 0.0.0.0:5000 (all interfaces)
Mobile cần:  172.168.99.41:5000 (specific IP)

🛠️ Các giải pháp đã áp dụng:
✅ Giải pháp 1: Dynamic IP Detection
// Thay vì hardcode IP
const API_BASE_URL = 'http://172.168.99.41:5000/api'
✅ Giải pháp 2: Tunnel Mode
Expo tunnel bypass network restrictions
Reliable connection qua exp:// protocol
Không phụ thuộc IP cục bộ
✅ Giải pháp 3: Server Binding
// Server listen trên tất cả interface
--urls="http://0.0.0.0:5000"

💡 Bài học và cách tránh trong tương lai:
🔧 Giải pháp lâu dài:
1. Environment Variables:
const API_BASE_URL = process.env.EXPO_PUBLIC_API_URL || 'http://172.168.99.41:5000/api';
2. Auto IP Detection:
// Có thể implement auto-detect IP
import { Platform } from 'react-native';
const getApiUrl = () => {
  if (Platform.OS === 'ios' || Platform.OS === 'android') {
    return `http://${getCurrentIP()}:5000/api`;
  }
  return 'http://localhost:5000/api';
};
3. Development Helper:
// Log để debug
console.log('🌐 Trying to connect to:', API_BASE_URL);
console.log('📱 Platform:', Platform.OS);
