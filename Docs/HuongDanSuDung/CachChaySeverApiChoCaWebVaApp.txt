🌐 Cách sử dụng hệ thống (Web + Backend):
🖥️ Web App:
# Truy cập web app
http://localhost:5000

# API endpoints
http://localhost:5000/api/test/ping
http://localhost:5000/api/auth/login
http://localhost:5000/api/auth/register

🚀 Khởi động hệ thống:
1. Khởi động Server (phục vụ web và API):
cd Backend\HealthySystem.API
dotnet run --urls="http://0.0.0.0:5000"

📊 Kiểm tra hoạt động:
Web App: Mở browser → http://localhost:5000
API Test: Click các nút test API trong web interface

💡 Lợi ích của cấu hình này:
✅ Single Server: Chỉ cần chạy 1 server cho web và API
✅ Consistent API: Cùng endpoints, cùng business logic
✅ Easy Deployment: Deploy 1 lần
✅ Development Friendly: Hot reload frontend
✅ Production Ready: Có thể scale và load balance

🔧 Cấu trúc thư mục sau khi setup:
Backend/HealthySystem.API/
├── wwwroot/          # Web app static files
├── Controllers/      # API controllers
├── Program.cs        # Server configuration
└── Properties/launchSettings.json  # Launch profiles

Chạy lệnh này để kiểm tra IP hiện tại (nếu cần truy cập LAN):
# Lấy IP hiện tại
$ip = (Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -like "172.*" -or $_.IPAddress -like "192.168.*"}).IPAddress
Write-Host "Current IP: $ip" -ForegroundColor Cyan
Write-Host "API URL: http://${ip}:5000/api" -ForegroundColor Green

# Test API
Invoke-RestMethod -Uri "http://${ip}:5000/api/health"

📝 GHI CHÚ QUAN TRỌNG
✅ Server phải chạy với http://0.0.0.0:5000 (không phải localhost)
✅ Tường lửa Windows phải cho phép port 5000
