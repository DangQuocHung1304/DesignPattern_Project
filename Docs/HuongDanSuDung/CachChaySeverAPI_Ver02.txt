Kiểm tra xem port 5000 có bị chiếm không:
Get-NetTCPConnection -LocalPort 5000 -ErrorAction SilentlyContinue

Bước 2: Khởi động Server API với cấu hình mới
cd "Backend\HealthySystem.API"
dotnet run --urls="http://0.0.0.0:5000"

Nếu lệnh dotnet trên lỗi thì dùng lệnh này:
dotnet run --project HealthySystem.API.csproj --urls="http://0.0.0.0:5000"
hoặc
cd Backend\HealthySystem.API && dotnet run --urls="http://0.0.0.0:5000"

Bước 3: Xác nhận server đã khởi động thành công

Bước 4: Kiểm tra các tính năng
Invoke-RestMethod -Uri "http://localhost:5000/api/test/ping"


📋 Các lệnh cần chạy theo thứ tự:
# 1. Mở PowerShell và chuyển đến thư mục project
cd "D:\2.CNPMNangCao\LyThuyet\Project"

# 2. Kiểm tra và dọn dẹp process cũ (nếu có)
Get-Process -Name "dotnet" -ErrorAction SilentlyContinue | Stop-Process -Force

# 3. Chuyển vào thư mục API
cd "Backend\HealthySystem.API"

# 4. Khởi động server
dotnet run --urls="http://0.0.0.0:5000"

🌐 Cách truy cập:

🔧 Nếu gặp lỗi:
Port bị chiếm: Get-NetTCPConnection -LocalPort 5000
Process zombie: Get-Process dotnet | Stop-Process -Force
Build error: dotnet clean && dotnet build
