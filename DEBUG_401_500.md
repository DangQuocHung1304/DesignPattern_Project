## Issue 1: Lỗi 401 - Token không được gửi

### Nguyên nhân:
Token được lưu với key `accessToken` nhưng có thể:
1. Chưa được lưu sau khi login
2. API interceptor đọc từ key sai
3. Token hết hạn

### Check token hiện tại:

**Mở Expo DevTools console và chạy:**
```javascript
import AsyncStorage from '@react-native-async-storage/async-storage';

// Check token
AsyncStorage.getItem('accessToken').then(token => {
  console.log('Current token:', token);
  if (token) {
    console.log('Token exists! Length:', token.length);
  } else {
    console.log('NO TOKEN FOUND!');
  }
});
```

### Test login và lưu token:

**Sau khi login thành công, token phải được lưu:**
```javascript
// In login success handler
await AsyncStorage.setItem('accessToken', response.data.accessToken);
console.log('Token saved!');
```

## Issue 2: Lỗi 500 - Backend Doctor Detail

### Nguyên nhân:
Line 93 trong DoctorsController.cs:
```csharp
PatientName = r.Patient.FullName
```

**Problem**: `r.Patient` có thể null hoặc `Patient.FullName` null!

### Fix Backend:

**File**: `Backend/HealthySystem.API/Controllers/DoctorsController.cs`

**Line 89-95** - Change to:
```csharp
Ratings = u.DoctorRatings
    .OrderByDescending(r => r.CreatedDate)
    .Take(10)
    .Select(r => new
    {
        Id = r.Id,
        RatingValue = r.RatingValue,
        ReviewText = r.ReviewText,
        CreatedDate = r.CreatedDate,
        PatientName = r.Patient != null ? r.Patient.FullName ?? "N/A" : "N/A"
    })
    .ToList()
```
